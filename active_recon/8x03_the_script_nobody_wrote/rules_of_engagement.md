# Rules of Engagement (signed)

Authorised: writing/running NSE scripts against talvi.example; discovery,
version detection, behavioural vulnerability confirmation, and credential
auditing of the synthetic Talvi management accounts.

Forbidden: exploitation, the EXPLOIT vulns state, destructive/state-changing
protocol commands, os.execute/system command execution, brute forcing system or
SSH accounts, exceeding the account lockout threshold, reading protected target
files. Confirm presence only.
