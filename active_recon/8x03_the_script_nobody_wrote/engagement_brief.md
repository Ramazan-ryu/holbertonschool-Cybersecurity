# Engagement Brief — Talvi Systems

Client: Talvi Systems, a Tallinn managed-cloud provider. Standard services run
alongside a bespoke internal management service on a non-standard port speaking a
custom protocol no off-the-shelf NSE script understands. Consultancy: Ridgeline
Security. Lead: Karim Haddad.

The Rules of Engagement authorise active scanning and credential auditing, NOT
exploitation. Build the tooling the library does not contain, confirm what is
present, and stop at confirmation. A version string is a suspicion, not a proof.
